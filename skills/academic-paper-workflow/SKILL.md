# Academic Paper Workflow

通用的学术论文全流程协作工作流。适用于计算机、医学、工科、实验科学、实证社科等绝大多数学科方向的学术论文准备与撰写。

核心机制为**分阶段推进**与**双硬性审批门禁**：Agent 负责摸清事实、查文献、做卡片、构思选题、设计实验与统计、绘图、拟定提纲和起草正文；但在“选题”与“提纲”两个关键决策节点，必须主动停止并等待用户拍板，严禁擅自越权推进。

---

## 核心原则与红线

1. **双硬门禁阻断（不可跳步）**：
   - **Gate 1（选题决策门禁）**：Phase 1 产出候选选题与对比推荐后，必须停下来让用户选择。未获明确选定前，禁止进入研究设计、提纲拟定与正文起草。
   - **Gate 2（提纲与论据门禁）**：Phase 2 产出详细提纲、实验/统计结果表与图表方案后，必须停下来让用户确认。未获明确确认前，禁止撰写摘要与正文段落。
2. **拒绝空想，事实先行**：
   - 若针对具体代码库、系统或数据集，必须先用 `search_files` / `read_file` 查验真实代码与数据，禁止凭简介或常识编造功能。
   - 所有实验数据、统计指标、对比基线必须来自实际计算或真实记录，严禁捏造 p 值、样本量或性能数字。
3. **真实文献，逐条下锚**：
   - 参考文献必须经过检索验证，具备真实可查的 DOI 或元数据；禁止幻觉引用，禁止在没有阅读证据的情况下空对空泛引。
4. **行文去 AI 味**：
   - 正文客观朴素，第三人称叙述，禁止“不仅……而且……”、“不是……而是……”、“深入探讨”、“赋能”等空泛转折与宣传套话。
   - 结论严格约束在证据边界内，不把相关性写成因果，不将内部单中心数据夸大为普遍结论。

## 五阶段流水线（Workflow Phases）

```
[资料/代码摸底] + [多源文献检索] + [核心文献精读]
                       │
                       ▼
            [3-5个候选选题与多维对比]
                       │
           🛑 GATE 1: 必须停下等待用户选题
                       │
                       ▼ (用户选定方向后)
   [研究问题与假设] + [实验/统计方案] + [数据处理与作图]
                       │
                       ▼
          [带论据与图表锚点的详细提纲]
                       │
           🛑 GATE 2: 必须停下等待用户确认提纲
                       │
                       ▼ (用户确认提纲后)
   [正文撰写: 方法→结果→讨论→引言→摘要标题]
                       │
                       ▼
   [参考文献逐字段核验] + [模拟同行评审与修订]
                       │
                       ▼
                [结构化归档交付]
```

### Phase 1: 基础核查、文献精读与选题构思

1. **项目与数据事实摸底**：
   - 针对工程/应用类论文：梳理输入输出、核心算法/模型、规则护栏、评估工具链、现有数据集分布、已测指标与缺失项。
   - 针对基础科研/实证类论文：核对试验设计、受试对象、分组干预、纳排标准、主要与次要终点、混杂因素控制。
2. **文献多源检索**：
   - 制定系统检索式，按领域查询主流数据库（PubMed、Crossref、IEEE Xplore、Scopus、arXiv 等）。
   - 提取元数据、去重、导出 `.bib`，并按“背景理论/同类方法/评测规范/讨论边界”打标归类。
3. **核心论文精读（Paper Card）**：
   - 挑选 5–10 篇最相关基线文献，拆解研究问题、数据集规模、输入类型、标签来源、模型/统计方法、主要结果、局限性与不可迁移结论。
4. **提出 3–5 个差异化选题方案**：
   - 建立在现有事实与可行数据之上，涵盖题目、研究问题、核心方法、所需数据、指标口径、预期贡献、局限与难点。
   - 输出多维对比表（创新性、工作量、数据门槛、实验周期、发表潜力等）并给出依据充分的推荐排序。
5. **🛑 触发 GATE 1**：
   - **交付产物**：项目事实清单、去重文献库、核心论文精读卡、候选选题对比表。
   - **执行动作**：停止工作，明确询问用户选择哪个方向，或提出具体调整意向。在此之后结束当轮回复。

---

### Phase 2: 研究设计、实验统计与提纲论证

*（仅在用户明确确认选定方向后启动）*

1. **研究问题与假设操作化**：
   - 拆解为可证伪的主要研究问题（Primary RQ）、次要问题（Secondary RQ）与理论假设。
   - 明确输入空间、操作变量、对照基线（Baselines）、主次评估指标与安全/负面指标。
2. **研究与统计设计审查**：
   - 审查独立分析单位（避免同一主体衍生样本膨胀自由度）、数据泄漏边界、标签独立性、拒答/异常值纳入策略。
   - 制定统计分析计划：置信区间计算方法、配对检验、多重比较校正、亚组分层与模型重复性信度。
3. **数据执行与图表制作**：
   - 处理真实数据，计算指标、分子分母、点估计与区间；保留完整清洗与计算脚本。
   - 制作论文图表（流程图、性能对比图、混淆矩阵/分层图、案例消融图），确保图表直接读取数据、注明误差与样本量，符合学术出版对比度与印刷规范。
4. **拟定详细论证提纲**：
   - 按目标期刊/会议规范搭建章节框架（如 IMRaD）。
   - 每节细化至段落论点、支撑数据、对应图表编号与引用文献定位。
5. **🛑 触发 GATE 2**：
   - **交付产物**：研究设计规范表、统计结果表与数据源文件、论文图表及代码、详细论证提纲。
   - **执行动作**：停止工作，明确请求用户确认提纲结构与论点安排。未获批准前不撰写正文。

---

### Phase 3: 证据驱动的正文撰写

*（仅在用户明确批准提纲后启动）*

1. **科学写作顺序**：
   - 顺序：**方法（Methods） → 结果（Results） → 讨论（Discussion） → 引言（Introduction） → 摘要与标题（Abstract & Title）**。
   - 严禁先写引言摘要再倒推实验细节。
2. **正文质检标准**：
   - **方法**：详实完整，足以供第三方复现，严谨陈述参数、数据划分与协议版本。
   - **结果**：只陈述事实与统计数字，数字与图表百分之百吻合，同时报出区间与样本量；不掺杂主观推测。
   - **讨论**：结合文献解释机制，直面异常结果与失败案例，独立辟出“局限性（Limitations）”章节，严禁过度延伸外推。
   - **引言**：从现实痛点与知识缺口切入，顺畅引出研究问题，避免宏大叙事。
   - **摘要**：结构化四要素（背景与目的、方法、核心结果、结论），字字有依据。

---

### Phase 4: 引用终验与模拟同行评审

1. **参考文献字段级交叉核验**：
   - 提取文稿全部引用，逐条核对作者姓名、年份、文章标题、期刊卷期页码及 DOI。
   - 排查 DOI 张冠李戴、作者漏人、卷期年份冲突，生成修正报告并更新 `.bib`。
2. **两阶段模拟同行评审**：
   - **阶段一：方法学盲审（Methodology Focus）**：从苛刻审稿人视角排查数据完整性、统计检验有效性、样本偏倚、结论过强等硬伤。
   - **阶段二：全面同行评审（Full Review）**：从领域契合度、创新增量、逻辑链条、图表规范与学术语态进行综合审查。
3. **形成修订清单**：
   - 根据评审意见标注 P0（致命漏洞）、P1（主要缺陷）、P2（文字润色），完成修改并留痕。

---

### Phase 5: 文件结构化归档与交付

所有文件统一保存至用户指定交付目录（默认 `E:\.hermes\论文工作流\<项目或选题名>\`）：

```text
├── 01-项目核查/       # 事实清单、数据探针与接口记录
├── 02-文献检索/       # 检索式记录、去重文献表、references.bib
├── 03-论文卡片/       # 核心基线论文精读卡 (Paper Cards)
├── 04-选题方案/       # 候选方向、多维对比矩阵、决策记录
├── 05-研究设计/       # 研究问题、实验协议、统计分析方案
├── 06-数据与统计/     # 清洗脚本、原始及汇总数据表、计算日志
├── 07-论文图表/       # 图表源脚本 (Python/R)、矢量图 (SVG/PDF)、预览图
├── 08-参考文献/       # 终验报告、修复后 clean_references.bib
├── 09-论文正文/       # 论文完整文稿 (DOCX / Markdown)
└── 10-评审与修订/     # 审稿报告、修改对照表、最终定稿
```

## 学科范式适配指南

| 论文类型 | 重点章节 | 核心关卡 |
|---|---|---|
| **计算机算法 / 模型改进** | 实验设置、消融实验、复杂度分析 | 数据集泄漏控制、基线公平性对比、随机种子稳定性 |
| **工程系统 / 移动应用** | 系统架构、交互链路、容错/快慢通道 | 真实响应延迟、并发/可靠性测试、真实可用性评估边界 |
| **医学初筛 / 辅助诊断** | 标签形成机制、诊断一致性、安全分诊 | 排除模型自产标签、敏感度/特异度置信区间、危险漏判与拒答分析 |
| **实证科学 / 统计推断** | 抽样设计、变量定义、稳健性检验 | 混杂因素控制、多重比较校正、效应量与真实独立分析单位 |

## 检查清单（Verification Checklist）

- [ ] 摸底基于真实代码/文件，区分了“已实现”、“未运行”与“计划中”。
- [ ] 检索覆盖主流数据库，每篇入选基线均完成 Paper Card 深度解构。
- [ ] 候选选题提供了结构化对比，且在 **Gate 1 处主动停下等待用户选择**。
- [ ] 研究设计明确了独立分析单位、主要/次要终点及局限性。
- [ ] 实验统计数字真实产生，图表脚本可一键复现并输出矢量格式。
- [ ] 提纲细化到段落与图表锚点，且在 **Gate 2 处主动停下等待用户批准**。
- [ ] 正文写作遵循“方法→结果→讨论→引言→摘要”顺序，语言客观精炼无 AI 套话。
- [ ] 参考文献完成逐条 DOI 及字段交叉验证。
- [ ] 经过方法学与同行评审双重审查，全部文件分类归档完成。
