# 研究与素材规范

## 建立证据表

对每个重要断言记录：`claim / source_url / paper_version / page_or_figure / evidence / scope / caveat / checked_date`。证据可以是准确的概括；长篇原文仅在确有适用依据时保存和呈现。

研究顺序：

1. 搜索用户提到的名称、确切标题、作者项目页和论文标识符，核对名称歧义。
2. 打开摘要页、原论文及项目页。记录首次预印本日期、会议发表日期、截图所用版本，三者可能不同。
3. 阅读机制图对应段落与实验设置，核对宣传数字的分母、任务、训练预算、硬件和评价方式。
4. 搜索关键转折的早期先例、后续版本及并行路线，避免“今年首次”的无依据说法。
5. 搜索网上图片以发现可用素材，最终从可追溯的原始来源获取；记录实际图源而非搜索缩略图地址。

每个关键数字至少回答：测了什么？在哪个任务？用多少真实数据？什么模型/硬件？报告的是成功率、平均进度、更新频率还是底层控制频率？单次曲线的阴影不能写成多次复现的置信区间。

## 叙事模板

每章包含有论点的标题、短解释、方法流程、原图及解释、证据边界、与下一章的连接。比较表使用统一维度，例如输入、预测对象、训练目标、推理时如何决策、是否输出动作、需要何种数据。

来自本次世界模型报告的可迁移检查：

- “潜在空间预测”并非某一后期路线才引入；分别比较表示、训练目标和决策接口。
- “在梦里训练”和“部署时生成动作”属于不同阶段，不能混写。
- 真机学习时长不等于无奖励设计、无人协助或所有机器人通用的保证。
- 视频逼真程度不等于物理精确性或可用于可靠闭环控制。
- “联合建模视频与动作”仍可能采用不同训练和推理顺序，应读方法细节。

这些是检查问题，不是可跳过检索的事实库。

## 原图与完整摘要

为每项素材保存：来源 URL、作者、论文标题、版本、页码/图号、用途、裁切/拼接说明、许可或其他适用依据。保留原始文件与制作记录在工作目录；不要默认把整篇论文发布进最终仓库。

截图建议：PDF 渲染 160–220 DPI；精细公式可提高。按实际版面分别裁标题/作者和完整摘要，再按阅读顺序拼接。不要把引言、无关版权图片或正文片段一起纳入。不要重排、补写或修复成看似原文的内容。若标题或摘要跨页，标明拼接页码。

`scripts/capture_regions.py input.pdf regions.json output.png --dpi 180`

区域 JSON 使用 PDF 渲染前的页面尺寸比例，原点为左上角：

```json
[
  {"page": 1, "box": [0.08, 0.07, 0.92, 0.25]},
  {"page": 2, "box": [0.08, 0.10, 0.92, 0.52]}
]
```

`page` 从 1 开始；`box` 为 `[left, top, right, bottom]`，各值 0–1。必须先看页面再确定区域。输出需要人工核对，脚本不会识别文字或保证摘要完整。

## 许可判断

以实际来源标示和适用条款为依据。arXiv 收录或免费阅读不等于全文、图表允许随意再发布；作者项目页也可能包含第三方版权内容。元数据与排版截图是不同对象，应核对拟复制内容实际适用范围。遇到不能完整呈现的摘要，提供自己的完整概括与原文链接，说明限制。不要用截图绕过文本引用限制。
