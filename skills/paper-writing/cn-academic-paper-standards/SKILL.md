# 中文学术论文写作与排版标准规范 (GB/T 7713.2 与 GB/T 7714)

本技能汇聚面向中国国家标准（GB/T 7713.2-2022《学术论文编写规则》、GB/T 7714《信息与文献 参考文献著录规则》）的高水平中文学术论文写作、深度润色与 python-docx 标准化排版全流程指南。

---

## 1. 适用场景与触发条件

- 撰写、修改或深度润色中文学术论文（期刊论文、毕业设计/学位论文、学术会议论文、申报评奖学术报告）。
- 对 AI 初稿或粗加工稿件进行“去 AI 腔”、去口语化、提升学术质感的深度重构。
- 自动化生成符合科技论文国家标准格式的 Word (.docx) 文件（标准三线表、图文交织、顺序编码制引文、统计学符号斜体等）。

---

## 2. 学术语态与文字润色底线（去 AI 腔与口语化）

学术论文应体现求真、严密、客观、克制的文字品格，严禁口语化表述与空洞的 AI 机械套话：

### 2.1 常见口语化表述的学术化转换
- 口语：“宠物主人手上最不缺的是照片” → 学术：“随着智能移动设备的普及，宠物主人习惯于采集患处实拍照片进行初步求助与健康记录”。
- 口语：“动不动就说‘没事’” → 学术：“在带病变样本中输出‘无病理性皮损’判定，呈现出显著的虚假安心（False Reassurance）倾向与临床漏诊风险”。
- 口语：“模型说得像不像回事” → 学术：“对多模态模型临床判读可靠性与行为安全性边界的系统审视”。
- 口语：“多看几眼” → 学术：“显式增强空间视觉注意力权重以捕获微观早期病灶”。
- 口语：“把两侧代价都摆在指标里” → 学术：“在量化指标维度完整呈现过度报告的冗余成本与假阴性漏诊的延误代价”。

### 2.2 杜绝 AI 套话与机械句式
- 禁用无信息增量的过渡套话：“围绕……展开”、“另一端的变化来自……”、“这指向同一个问题”。改用内在逻辑推进与具体研究主旨连接。
- 禁用“不是……而是……”等转折说教句式，一律直接陈述客观事实与处理方法。
- 杜绝第一人称流水账（“我们对模型进行了测试……我们发现……”），全面转为第三人称客观叙述（“本研究评估了……”、“实验结果表明……”）。

### 2.3 标点符号与用字硬性规范
- 引号：一律采用中文全角双引号“ ”（U+201C/U+201D），严禁使用 ASCII 直引号 `"` 或直角引号「 」。
- 标点：正文句段一律使用中文全角标点（，。、；：？！）。
- 范围连接号：数值区间使用全角波浪号“～”或短横线“—”，全文保持一致。

## 3. 国家标准结构与版面规范 (GB/T 7713.2-2022)

### 3.1 题名与署名
- 题名：准确、简明反映核心研究对象、方法与范围，一般不超过 25 字；黑体二号居中。
- 署名及单位：居中排列，楷体五号。

### 3.2 结构化摘要与关键词
- 摘要四要素：采用【目的】【方法】【结果】【结论】结构化形式；重点突出定量数据、置信区间与关键发现；字数通常 300～600 字；宋体五号，左右各缩进 2 字符。
- 关键词：3～8 个，按词义范围由大到小或研究逻辑排列，以分号“；”分隔；黑体小五标注词头。

### 3.3 层次标题与编号
- 采用阿拉伯数字分级连续编号（1、1.1、1.1.1），左顶格排。
- 一级标题：黑体小三/四号，段前 12～14 pt，段后 4～6 pt。
- 二级标题：黑体五号加粗，段前 8～10 pt，段后 2～4 pt。
- 正文段落：宋体五号（10.5 pt），西文 Times New Roman，行距 1.25～1.3 倍，段首严格缩进 2 字符（21 pt）。

## 4. 图、表与统计学规范

### 4.1 科技论文标准三线表
- 严格遵循标准三线表形态：
  - 顶线：1.5 pt 单实线（w:sz='12'）
  - 栏目线（表头下线）：0.75 pt 单实线（w:sz='6'）
  - 底线：1.5 pt 单实线（w:sz='12'）
  - 坚决杜绝竖线、斜线与表体内部网格杂线。
- 表题：置于表格上方居中，黑体小五号加粗（如“表 1  各模型在四种策略下的核心性能指标”）。
- 表头行必须设置 `w:tblHeader`（跨页重复表头）与 `w:cantSplit`（单元格防拆分）。
- 表注：置于表格下方左对齐或两端对齐，宋体小五号（8.5 pt）。

### 4.2 插图与图题规范
- 先文后图：插图紧跟正文首次引用的自然段后，禁止插图出现在引用文本之前。
- 图题：置于插图正下方居中，黑体小五号加粗（如“图 1  VetAI 小程序诊断流程图”）。
- 图版在 Word 中版芯居中，标准宽度控制在 14.5～15.5 cm。

### 4.3 统计学符号与变量格式
- 样本量 *n*、总体样本 *N*、检验值 *p*、卡帕系数 *κ*、均值 *M*、相关系数 *r* 等统计量符号一律使用斜体。
- 置信区间标准写法：95% CI: XX.X%～XX.X%。

---

## 5. 参考文献著录规范 (GB/T 7714 顺序编码制)

- 正文引文标注：按正文首次出现的先后次序，使用方括号上标或正文平排数字标注，如“Kang等[1]”、“（Presacan等[5]；Kompa等[6]）”。
- 著录格式：
  - 期刊：[序号] 主要责任者. 题名[J/OL]. 刊名, 年, 卷(期): 起止页码. DOI: xxx.
  - 著者 3 人以内全部列出，3 人以上列出前 3 人，后加“, 等”或“, et al.”。
  - 文末参考文献列表采用悬挂缩进 2 字符排版。

## 6. 标准三线表与排版脚本参考代码 (Python-docx)

```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def format_three_line_table(table):
    tblPr = table._tbl.tblPr
    borders = OxmlElement('w:tblBorders')
    
    # 顶线与底线 1.5pt (sz=12)
    for edge in ['top', 'bottom']:
        el = OxmlElement(f'w:{edge}')
        el.set(qn('w:val'), 'single')
        el.set(qn('w:sz'), '12')
        el.set(qn('w:color'), '000000')
        borders.append(el)
        
    # 无竖线与表内横线
    for edge in ['left', 'right', 'insideV', 'insideH']:
        el = OxmlElement(f'w:{edge}')
        el.set(qn('w:val'), 'none')
        borders.append(el)
    tblPr.append(borders)
    
    # 表头行栏目线 0.75pt (sz=6) 与跨页重复表头
    hrow = table.rows[0]
    hrow._tr.get_or_add_trPr().append(OxmlElement('w:tblHeader'))
    hrow._tr.get_or_add_trPr().append(OxmlElement('w:cantSplit'))
    for cell in hrow.cells:
        tcBorders = OxmlElement('w:tcBorders')
        b = OxmlElement('w:bottom')
        b.set(qn('w:val'), 'single')
        b.set(qn('w:sz'), '6')
        b.set(qn('w:color'), '000000')
        tcBorders.append(b)
        cell._tc.get_or_add_tcPr().append(tcBorders)
```
